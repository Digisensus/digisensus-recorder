# Security

Digisensus Recorder records calls, so we treat security reports as a priority.

If you find a vulnerability, email support@digisensus.com. Please include the app version (Settings › Advanced), your macOS version, and steps to reproduce. We reply within three working days and keep you informed until the fix ships. Please don't open a public issue for security problems before then.

Supported: the latest release, from the Mac App Store, the direct download or the GitHub releases page. Recordings stay on your Mac; the only data that leaves it is audio you choose to transcribe and the account details described in the Privacy Policy at https://recorder.digisensus.com/privacy.
